# zhouyi_skill
把《周易》做成可执行的 AI skill：起卦、定主辞，朱熹《本义》与王弼注孔疏《正义》两家并列解读，不做确定性预言。
An executable I Ching skill: cast a hexagram, resolve the primary line, and read it through both Zhu Xi's Benyi and Wang Bi/Kong Yingda's Zhengyi — no fortune-telling.

《周易》在这里不是算命，是一套结构化的处境反思工具。  它把两套最主流的读法放进同一个入口：  朱子《本义》：象 → 占 → 戒，重占断，强调「占者如是」的条件； 王弼注孔疏《正义》：时 → 位 → 应，重义理，先把处境说清。 起卦、排卦、定主辞交给脚本（大衍、三钱、手报六爻），主辞依《易学启蒙·考变占》；解读交给两本书的能力卡，各出结论、依据原文、解释链，分歧写明，不调和。  引文全部回底本核对：《本义》88 条、《正义》77 条，零排除。不做确定性预言，不替代医疗、法律、投资判断。
The I Ching here is not fortune-telling — it is a structured way to think through a situation.
Two classical readings sit behind one entry point: Zhu Xi's Benyi (image → divination → caution) and Wang Bi/Kong Yingda's Zhengyi (time → position → correspondence). Casting and line selection are handled by scripts following the Yijing Meng change rules; interpretation is handled by two sets of capability cards that state conclusions, cite sources, and mark disagreements instead of smoothing them over.
Every quotation is checked against the source texts (88/88 and 77/77, zero exclusions). No deterministic predictions.
